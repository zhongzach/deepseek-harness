# Agent Note: 模型配置之前的操作授权

Status: implemented

[English](2026-08-27-operation-authorization-before-model-configuration.md) | 中文

## 问题

部署方需要限制模型选择和自定义提供方配置，同时不把账号或计费策略写入 agent loop（智能体循环）。禁用客户端控件无法保护直接 RPC 调用，而默认值保存回调执行时，会话选择已经改变。模型目录中的资格也必须区别于提供方路由，以及稍后实际执行模型请求的权限。

## 决策

API 网关持有串行的操作前授权事件。在修改已解析的会话选择、变更设置或凭据、调用模型发现之前，它会等待部署策略。监听器收到独立的元数据副本，不含凭据值；设置元数据复用归属 schema 的机密脱敏器，并保留修改路径。拒绝会保持操作状态不变，返回 `operation-denied`、可公开的原因码与不可重试标记。监听器意外失败时拒绝，而不是继续执行。

目录投影是作用于共用 Host 目录的独立串行事件。部署方可以筛选可见的提供方分组、模型和提供方失败行，并为保留的模型发布选择资格，而不改变模型标识或提供方路由。composer、`/model` popup 与目录控制器都会拒绝仍可见的禁用行。

授权改变时，部署方通过解析器使共用目录失效，并通过 `CommandUiContract.dismissPopups` 关闭匹配的 `/model` 弹窗。目录失效会清空可选行，但保留当前选择；弹窗关闭会中止进行中的选项读取，撤销迟到结果的写入权限，不消耗命令文本、不改变焦点，也不关闭其他命令的弹窗。模型标识、已保存的提供方配置和凭据保持不变。目录元数据和成功选择都不会预留次数，也不授权未来的模型请求；执行授权仍由操作归属方负责。

可选的可用性动作提供由部署方持有的标签与不透明 id。模型选择器通过独立的可用按钮发布本地帮助事件，模型行保持禁用。命令弹窗会对筛选行中的动作去重，并在派发帮助之前关闭，保留命令文本，让目标弹窗获得焦点。登录、会员与购买窗口由产品账号 UI 负责；通用选择器既不解析账号错误码，也不重试被拒绝的操作。

## 考虑过的替代方案

**仅在客户端控件检查。** 直接 RPC 调用方与已打开的陈旧菜单可以绕过客户端展示。网关在执行器之前检查，部署的 LLM（大语言模型）策略负责最终模型调用检查。

**在默认值持久化时拒绝。** 此时会话已经切换；存储拒绝按设计会保留成功的会话内切换。因此授权发生在赋值之前。

**添加竞争性的 RPC 拦截器。** 是否执行授权会取决于拦截器顺序，而网关方法仍然可以直接调用。事件因此由操作本身发出。

**把订阅与次数策略写入 harness。** 这些决策属于各部署方。通用的操作描述、拒绝字段和目录可用性可以覆盖现有消费方，无需引入产品账号服务。

**把帮助作为另一个可选模型行。** 模型选择与账号导航有不同的副作用。独立帮助回调可以防止意外的模型 RPC，而底部区域使解决入口在大型目录滚动或按模型名称筛选时仍可见。

## 结果与代价

没有策略时，网关保留普通行为，因此受限产品必须组合其授权插件。直接编辑设置文件或调用提供方服务不在此 API 事件范围内；部署方仍需校验受保护路由，并为实际模型执行授权。机密脱敏继承设置 schema 支持的容器，不另建一套机密模型。

执行器测试通过进程内 fetch 载体选择模型，验证拒绝既不改变会话，也不改变默认值。配置测试验证设置不变、凭据保留、模型发现未调用，以及元数据不含机密。客户端测试覆盖禁用行的指针、键盘和控制器选择、可见原因及共用目录失效。弹窗生命周期测试覆盖按命令关闭、命令文本和焦点不变，以及忽略迟到的选项结果；产品接线测试覆盖账号失效。真实的模型选择器与弹窗组件通过插件动作事件覆盖点击、Enter 和 Space，验证不发起模型选择 RPC、不消耗命令，以及先关闭再派发帮助。产品组合负责账号生命周期与最终调用验证；这些通用测试不需要外部模型请求。
