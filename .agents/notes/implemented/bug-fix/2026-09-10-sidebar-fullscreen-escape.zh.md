# Agent Note: Escape 返回普通侧栏

Status: implemented

[English](2026-09-10-sidebar-fullscreen-escape.md) | 中文

## 问题

可编辑文件标签全屏时会覆盖会话。缺少键盘退出操作，会让用户只能寻找面板控件返回，包括光标仍在编辑器内的场景。

## 决定

当前会话的面板处于可见全屏状态时，由右栏 UI 插件处理 Escape。Escape 与退出按钮共用动作：宽屏恢复 push 模式，自动窄屏全屏收起面板。两个操作都不删除标签记录，也不重挂载文档内容。

监听器在编辑器处理后响应无修饰键、非长按重复的 Escape，排除输入法组词及已处理的事件。捕获阶段记录已经打开的语义浮层，防止浮层同步关闭后，同一按键继续退出全屏。退出全屏、切换会话或卸载时，两个监听器都会移除。

## 考虑过的替代方案

**各文件插件分别实现 Escape。** 公开标签动作未暴露呈现形态切换，分栏中的多个文档还会竞争窗口级监听。

**关闭并重新打开当前文件。** 删除标签会改变它的生命周期，并可能丢失编辑状态；退出全屏是布局动作，不是关闭文档。

## 结果与取舍

修正只位于右栏 UI 插件，不新增公共 API、Session 事件、模型调用或 Agent 循环改动。嵌入式编辑器已经处理的键盘事件仍归它所有；隔离 iframe 文档内的键盘事件不会传到父页面监听器。

## 验证

侧栏席位测试覆盖宽窄屏退出、标签身份、浮层优先、原生选择框、输入法、修饰键、长按重复及监听器清理。WriterX 的真实侧栏编辑器回归还检查 Escape 前后，聚焦的文本框、未保存文本和选区均保持不变。
