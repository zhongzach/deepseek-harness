# Agent Note: 产品 Workspace UI 适配

Status: implemented

[English](2026-09-14-product-workspace-ui-adapters.md) | 中文

## 问题

管理领域文档的产品需要原生 Workspace 树与 Session 导航，但不应要求用户理解文件系统术语。复制目录树会重复实现草稿、选择与目录接纳；让文档共享同一个 cwd 会削弱归属边界。

## 决策

原生控件保留布局和默认行为。可释放的导航策略可以处理空状态的新会话，并将草稿保留在原 Workspace。目录流回调通过现有可取消导航，把可选准备操作传给已解析的 Session。可选改名插槽允许产品编辑文档元数据，而不是带消歧后缀的 Workspace 别名。显式 locale 覆盖替换选定文案，基础词典仍保持单一所有者。

## 考虑过的替代方案

**替换整个侧栏和输入框。** 这会重复实现归属管理，并让视觉与交互行为产生分歧。

**重新注册基础词典。** 这会违反词典所有权，并将产品激活顺序耦合到翻译文案。

**在原生包中加入领域专有名称。** 这会把引擎 UI 耦合到写作产品；这里的扩展只承载回调和字符串。

## 影响

Session 路径、日志、归属和模型分发保持不变。产品可以从准备回调提交正常消息，但本包不会自行生成消息。除非产品策略明确禁用，原生用户仍保留草稿转移行为。卸载产品会恢复原生导航、改名回退和翻译。

## 测试

Locale 测试覆盖分层覆盖与释放。Workspace 服务测试覆盖拒绝重复策略和默认行为恢复。原生选择器与浏览器测试保留默认接纳和改名行为；产品真实组合浏览器测试验证新增回调、改名插槽和跨 Workspace 草稿。
