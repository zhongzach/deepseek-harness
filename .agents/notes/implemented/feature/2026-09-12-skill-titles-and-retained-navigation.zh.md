# Agent Note：面向用户的 skill 标题与常驻导航

Status: implemented

[English](2026-09-12-skill-titles-and-retained-navigation.md) | 中文

## 问题

写作组合需要可读的 skill 标题，但不应改变调用 ID。书稿目录必须在打开文档后仍可访问。只有一个 View 的会话也为不存在的选择器预留了空间。这些是可复用的目录与 shell 问题，不是章节工作流状态。

## 决策

`SkillSummary.displayName` 在注册表收集与加载过程中携带可选的非空标题。文件系统提供方读取 `display-name` frontmatter，`skills/list` 在不激活 Agent 的情况下传递标题。查找、重名裁决与模型调用仍使用 kebab-case `name`。产品导入器负责转换用户编写的名称；文件系统提供方不改写 skill 文件。

具有引导入口的页面类型可以启用 `retainAsDefault`。最低的引导顺序决定保留的默认页，同序时按注册顺序选择。右栏 store 在每个展开的停靠格首位保留该页，拒绝关闭或替换，并在移走或浮出后回填导航，不抢当前文档焦点。chip 与菜单使用相同的关闭判断。浮动副本仍可关闭。移除此选项即可解除保护；普通组合保留原有的默认页与关闭规则。

会话 header 仅在选择器存在时预留其所在行。单 View 组合使用紧凑的单行。多个 View 保留页签行。

## 验证

文件系统与冷会话目录测试断言标题传递不会改变调用查找。常驻导航测试覆盖直接打开文件、拒绝关闭与替换、分栏、浮窗、移除策略、默认选择、排序及撤销重做。消费此能力的 WriterX 浏览器冒烟测试覆盖中文 skill 导入并实际调用、51 像素单行 header，以及关闭文件后返回常驻书稿页签。

## 考虑过的替代方案

**用本地化标题替换调用 ID。** 这会改变工具查找和重名裁决，并破坏已有引用。分离标题与身份可以避免这种耦合。

**用产品 CSS 隐藏导航关闭按钮。** 键盘、上下文菜单和编程式关闭仍可移除该页。store 管理的可选策略让所有路径保持一致，普通 tab 类型不受影响。

**始终预留两行 header。** 只有一个 View 的组合会继续显示空白第二行。选择器是否存在已经提供了所需的布局条件。

## 影响

消费方无需翻译 skill 指令或改变持久化会话格式，即可展示本地化标题。常驻导航在每个停靠格占用一个 tab；其浮动副本不受保护。产品专属的名称、字数、目标控件及压缩结果展示仍位于原生 shell 包之外。
